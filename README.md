# 30-Day Technical PM Roadmap

A structured technical portfolio — from Python fundamentals to system architecture. This project tracks my 30-day Technical PM preparation journey.

## 📅 Day-wise Breakdown

### Day 1-10: Python & Data Structures
**Goal:** Build strong Python fundamentals and data structure knowledge.

**Day 1:**
- Python basics, variables, data types
- Control flow (if/else, loops)
- Functions and scope

**Day 2:**
- Data structures: lists, tuples, dictionaries, sets
- Common operations and time complexity
- Practice exercises

**Day 3:**
- Object-Oriented Programming (OOP)
- Classes, objects, inheritance, polymorphism
- Real-world examples

**Day 4-6:**
- Algorithms basics
- Searching (binary search)
- Sorting (bubble, insertion, merge, quick)
- Time and space complexity analysis

**Day 7-10:**
- Practice problems on platforms:
  - LeetCode (Easy/Medium)
  - HackerRank
- Weekly review and gap analysis

### Day 11-20: System Design Fundamentals
**Goal:** Understand core system design concepts and architecture patterns.

**Day 11:**
- Introduction to System Design
- Scalability, availability, reliability
- Monolithic vs microservices

**Day 12-14:**
- Load Balancing
- Types of load balancers
- Algorithms and strategies
- When to use each type

**Day 15-17:**
- Database Systems
- SQL vs NoSQL
- Indexing, replication, sharding
- CAP theorem

**Day 18-20:**
- Caching Strategies
- In-memory caches (Redis/Memcached)
- Cache eviction policies
- CDN implementation

### Day 21-30: Advanced Concepts & Mock Interviews
**Goal:** Cover advanced topics and simulate interview scenarios.

**Day 21-23:**
- Message Queues
- RabbitMQ, Kafka basics
- Use cases and patterns
- Asynchronous processing

**Day 24-26:**
- Security Basics
- Authentication vs Authorization
- OAuth, JWT tokens
- Common vulnerabilities

**Day 27-28:**
- CAP Theorem deep dive
- Distributed systems challenges
- Real-world case studies

**Day 29-30:**
- Full mock interviews
- System design interviews
- Behavioral interviews
- Feedback and improvement plan

## 🚀 Running the Code

### Prerequisites
- Python 3.8+
- pip (Python package manager)

### Setup
1. Clone the repository:
```bash
git clone <repo-url>
cd systems-intuition
```

2. No external dependencies are currently required.

### Usage
Each day has its own file:
```bash
# Run Day 1 exercises
python day1.py

# Run Day 2 exercises
python day2.py

# ...and so on
```
